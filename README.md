* **升级阈值设计**：定制固定等级所需经验表及通用经验计算公式，采用“前期升级快、中后期放缓”的成长曲线。
* **创新双重门槛模式（模型B）**：采用“经验达标 + 建设任务”双重升级门槛，为 `Lv1` ~ `Lv7` 分别配置种植次数、收获次数、装饰数量、好友互动、连续打卡等解锁条件，摒弃无脑金币一键升级的传统模式。
* **三段式升级交互体验**：设计“升级预热提示 $\rightarrow$ 点击升级仪式动画 $\rightarrow$ 升级结算弹窗”的完整交互链路，配套岛屿地块扩张、建筑翻新、夜景解锁等可视化画面变化。
* **功能解锁闭环**：按等级拆分每一级农田、种子、装饰、社交功能的解锁内容，明确 1~5 级岛屿外观差异化表现，完美实现“专注 - 耕种 - 升级 - 解锁”的产品闭环。
* **开发落地支持**：输出标准化前后端数据结构代码、升级可行性判断逻辑函数，提供 MVP（最简可行产品）落地开发方案，有效降低组员的开发成本。
