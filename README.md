## MA YUXIN
负责 Pomoland 项目的基础架构(前后端 + 云存档)搭建,并主导 AI 任务拆解模块的 API 接入与 Prompt 体系化优化(SMART)约束、递进逻辑、金币规则、反问机制、人性化鼓励语),同时修复打卡天数显示问题。

  一、网站基础搭建
  - 搭建 Pomoland 项目的前后端一体化框架(server.js + app.js + index.html + styles.css)
  - 配置云存档体系(SQLite + UID/密码鉴权):/api/auth/register、/api/auth/login、/api/state 等接口
  - 配置 npm 脚本(npm start / npm test)与 GitHub Actions 测试流水线

  二、AI 拆解任务 — API 链接与 Prompt 优
  核心改动集中在 server.js 的 /api/generate-tasks 端点,前端零侵入消费新字段。

  1. 接入 AI 接口 — 完成 API 链路打通,封装请求/响应格式,前端 normalizeTask 自动解析新字段。

  2. SMART 硬约束 — 每个任务必须满足 Specific / Measurable / Achievable / Relevant /
  Time-bound,杜绝"加油写""努力学一下"这类空话。

  3. 递进逻辑动态化 — 不再固定 4 个并列任务,AI
  先识别目标领域(学习/写作/项目/创意/运动/习惯养成),再选最贴合的推进模板,后一个任务建立在前一个的成果上。

  4. 任务数量按复杂度浮动 3–6 个 — 简单 3 个、常规 4 个、复杂 5–6 个。

  5. 金币奖励规则化 — 按时长分档(5–15min/3–6 金币 … 55–60min/21–25 金币),高难度额外 +20–30%。

  6. 温和反问机制 — 用户输入极短目标(如"学习""跑步")时,AI 仍给出 3 个轻量任务,并在鼓励语第 3
  句自然反问一句关键问题,引导下次输入更精准目标。

  三、打卡天数显示优化
  修复打卡内容的「连续天数」(streak / 连续打卡)显示问题,统一相关文案(statStreak、checkInTitle、stepReturn 等)。

  四、拆解任务界面鼓励语优化
  将 AI 鼓励语(encouragement)塑造成「坐在用户身边的小番茄宠物」口吻:
  - 共情先行:先承认目标难度,再聊今天这几步
  - 建立连接:多用「我陪你」「你已经…」
  - 禁止命令词:加油 / 坚持 / 必须 / 务必 / 赶紧
  - 禁止过度承诺:轻松完成 / 一定能 / 绝对没问题
  - 不预测未来结果,只聚焦今天这一小步;2–3 句自然流畅,不喊口号、不用 emoji

  - 建立“云端存档”机制：用户关键状态（资源、任务、岛屿进度等）可写入服务器并在登录后恢复，解决仅靠 localStorage 导致的丢失与跨设备不可用问题。  

- **真实好友系统与互动闭环落地**  
  - 实现“真实好友”全流程：按 UID 搜索用户、发送好友请求、展示待处理请求、同意/拒绝、维护好友关系表。  
  - 实现参观好友岛屿的数据接口：读取好友的岛屿状态并在前端展示（等级、农田、宠物、装饰等概览信息）。  
  - 实现互动接口与资源变更：浇水/偷果实/赠送礼物等操作会真实影响双方云端存档，并对结果做错误处理（例如礼物无效、背包数量不足等）。  
  - 处理“云端同步与冲突”问题：在互动后主动拉取最新云端状态并刷新本地状态，避免因自动保存覆盖他人对自己存档的修改，保证互动结果可靠一致。  

- **三语本地化（i18n）与动态内容适配**  
  - 系统性梳理并清理 Island/Friends 中的硬编码简体中文，将关键文案统一收敛到语言包，补齐 **zh-CN / zh-HK / en**。  
  - 覆盖静态与动态两类内容：除按钮/标题外，也处理地块状态（空地/锁定/可收获）、作物成长阶段、升级条件与奖励、每日任务/订单、好友互动提示等动态渲染文本。  
  - 统一多语言渲染方式：在 HTML 使用 `data-i18n`/`data-i18n-placeholder`，在 JS 使用本地化函数/映射层，避免出现“UI 已翻译但提示仍是中文”的割裂体验。  
  - 对“模板化提示”进行适配：针对带变量的提示（数量、等级、物品名等）做统一处理，使提示信息也能随语言切换且不破坏业务逻辑。  

- **AI 今日计划语言一致与输出稳定**  
  - 改造 AI 生成任务接口，使 AI 输出内容与当前语言一致：任务名称、鼓励语等不再固定中文，能够随 `language` 参数输出对应语言。  
  - 强化返回结构约束：要求 AI 仅返回稳定 JSON 结构（固定字段与类型），降低前端解析失败与异常回退的风险。  
  - 同步优化“生成过程提示”：planning steps 的提示文案也随语言返回，避免过程英文/结果中文的体验不一致。  
  - 保持可维护性：Prompt 与系统指令分层组织，便于后续继续迭代任务质量、语气风格与字段扩展。
